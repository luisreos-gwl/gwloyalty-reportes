# Reporte mensual GW Loyalty
Scripts que usa la skill `reporte-mensual-gw-loyalty`.
- `analyze.py <excel> <AAAA-MM> <pagado> "<Negocio>" [salida.json]` -> calcula las metricas.
- `build_report.js <salida.pptx> <metricas.json>` -> arma las 5 laminas (usa logo_blanco.png y logo_tinta.png de la misma carpeta).
